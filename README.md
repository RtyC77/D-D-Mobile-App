# D&D 5e Tracker (Android)

Aplicativo simples para acompanhar:
- Pontos de vida atuais e máximos.
- Slots de poção (total e usados).
- Valores das habilidades com modificador automático.

## Requisitos
- Android Studio (Hedgehog ou superior)
- SDK 34
- JDK 17

## Como executar
1. Abra a pasta no Android Studio.
2. Aguarde o Gradle sincronizar.
3. Rode o app em um emulador ou dispositivo Android.
